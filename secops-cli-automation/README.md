# SecOps CLI Automation · Fundamentos de Linux

Ejercicios de administración básica en Linux: permisos y atributos de fichero (`chmod`, `chattr`), scripts simples en Bash (listado, conteo, info de red) y manejo del sistema de ficheros. Práctica de base, no automatización de seguridad en producción.

## Por qué sigue aquí

El control de permisos y atributos a nivel de fichero es, en miniatura, el mismo principio que el *least privilege* (PoLP) que se aplica después a gran escala en IAM/RBAC (ver `profile-career-roadmap` y la experiencia en Seccion9/Glovo) — y los scripts de aquí son la base de los que luego se usan para hardening post-auditoría.
