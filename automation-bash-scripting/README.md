# Automatización Básica · Bash / Manejo de Ficheros

Ejercicios introductorios de scripting en Bash: creación, copia, renombrado y gestión de permisos de ficheros desde línea de comandos. Práctica de fundamentos de CLI, no una auditoría ni un proyecto de automatización en producción.

## Por qué sigue aquí

Son la base sobre la que se apoya después cualquier automatización real (hardening con Ansible, scripts de triage, recolección de evidencia en IR) — sin soltura en el shell, esas tareas se hacen más lentas y con más errores manuales.
