# Gamified Defense Drills · Python Básico

Ejercicio introductorio de Python (lógica de programa, estructuras de control) planteado como un mini-juego. Práctica de fundamentos de programación, no un ejercicio de seguridad ofensiva/defensiva en sí mismo pese al nombre del reto.

## Por qué sigue aquí

Saber programar, aunque sea a nivel básico, es lo que luego permite leer y adaptar PoCs públicos, escribir reglas de detección personalizadas o automatizar análisis en vez de depender solo de herramientas con interfaz gráfica.
